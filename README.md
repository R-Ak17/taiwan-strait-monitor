# Taiwan Strait Monitor

An open-source (OSINT) map of the Taiwan Strait, built as an academic project.
Case studies of **Kinmen**, **Matsu** and **Penghu**; strait-wide legal lines,
airspace, depth and cables; and an interactive **Taiwan–PRC military balance**.
Every layer is sourced in `data/sources.json`, and the analytical layers are
generated by the scripts in `tools/`, so the work can be checked and re-run.

It is a static website: one HTML page plus JSON data files. No build step,
no server code, no API keys.

## Run it on your computer

Browsers block a page from reading local data files when you just double-click
`index.html`, so serve the folder instead:

```bash
cd taiwan-strait-monitor
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy: GitHub + Vercel

1. **GitHub.** Create a new repository (e.g. `taiwan-strait-monitor`, public).
   Upload the *contents* of this folder (`index.html`, `data/`, `tools/`,
   `README.md`) with "Add file → Upload files", or with git:
   ```bash
   git init
   git add .
   git commit -m "Taiwan Strait Monitor: Phase 1"
   git branch -M main
   git remote add origin https://github.com/<your-username>/taiwan-strait-monitor.git
   git push -u origin main
   ```
2. **Vercel.** Sign in with GitHub at vercel.com → "Add New… → Project" →
   import the repository. Settings:
   - Framework preset: **Other**
   - Build command: *leave empty*
   - Output directory: *leave empty* (the repository root)
   
   Deploy. Vercel gives you a public `*.vercel.app` address, and redeploys
   automatically every time you push a change to GitHub.

**Alternative: GitHub Pages.** Repository → Settings → Pages → "Deploy from a
branch" → `main` / root. The site appears at
`https://<your-username>.github.io/taiwan-strait-monitor/`.

## Project structure

```
index.html            the whole interface (MapLibre GL JS from unpkg, fonts from Google Fonts)
data/
  land.json           coastlines: strait-wide, plus detailed Kinmen, Matsu, Penghu
  zones.json          Kinmen prohibited/restricted waters (27 official corners)
  equidistance.json   computed UNCLOS Art. 15 lines (Kinmen, Matsu)
  baselines.json      Taiwan's 1999/2009 baselines, 12 nm and 24 nm zones
  adiz.json           Taiwan ADIZ (AIP ENR 1.12-1)
  bathymetry.json     depth bands (Natural Earth)
  cables.json         submarine cables (OpenStreetMap)
  infrastructure.json ports, airports, bridges, garrison islands (Taiwan and PRC)
  military.json       Balance tab: 18 metrics with source, year, definition, caveat
  notes.json          the research notes shown in the Notes pane
  sources.json        provenance, licence and limitations for every layer
tools/                Python scripts that generate the data files
```

## Rebuilding the data

The scripts need Python 3 with `shapely`, `pyproj` and `pyshp`
(`pip install shapely pyproj pyshp`) and these inputs:

| Script | Input |
|---|---|
| `build_land.py` | `map.geo.json` from the npm package `@geo-maps/earth-lands-100m` |
| `build_bathymetry.py` | a checkout of github.com/nvkelso/natural-earth-vector (`10m_physical/ne_10m_bathymetry_all`) |
| `build_zones.py` | `data/land.json`; Kinmen corner coordinates are typed in from the Mainland Affairs Council map |
| `build_baselines.py` | `data/land.json` and an Overpass-turbo GeoJSON export of submarine cables |

Run them from the project root, e.g. `python3 tools/build_zones.py`.

## Data licences and credits

- Coastlines and cables: © OpenStreetMap contributors, **ODbL 1.0**. The
  attribution shown on the map must stay visible.
- Depth bands: Natural Earth, public domain.
- Official sources (Taiwan MND, Executive Yuan, Mainland Affairs Council, CAA AIP)
  and research sources (US DoD, IISS, AMTI/CSIS, news reports) are cited per
  layer in `data/sources.json` and per figure in `data/military.json`.
- Infrastructure coordinates come from Wikipedia (CC BY-SA); each site links
  to its article.

## Known limits

- Military force counts come from the US DoD's 2022 report; newer editions
  could not be retrieved when the data was compiled (November 2026).
- Matsu's restricted waters are described, not drawn: no official coordinates
  were found.
- PLA installations are not plotted.

*Coordinates, zones and computed lines are for research and education, not
navigation.*
